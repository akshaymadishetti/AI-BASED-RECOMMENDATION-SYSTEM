DESCRIPTION

This project demonstrates a User-Based Collaborative Filtering recommendation system implemented in Java using Apache Mahout. The system reads user-item preference data from a CSV file and generates personalized item recommendations for users based on the preferences of similar users.

Features

Reads user-item-preference data from a CSV file.

Calculates similarity between users using Pearson Correlation.

Finds the nearest neighbors of a user.

Generates personalized recommendations for users.

Console-based output for easy testing and extension.

Technologies Used

Java 8

Apache Mahout 0.9 (Taste API)

CSV files for storing user-item ratings

Maven for project management and dependency handling

CSV Data Format

The CSV file should have the following format:

userID,itemID,preference
